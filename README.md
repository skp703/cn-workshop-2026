# Modern Curve Number Hydrology

Participant materials for the 2026 ASCE–EWRI Watershed Management Conference
workshop on Curve Number theory, Google Earth Engine, and participant-directed
hydrologic investigations.

The four-hour workshop includes a ten-minute introduction, thirty minutes of
Curve Number theory, a twenty-minute guided Earth Engine exercise, an optional
Earth Engine exploration interval, and ninety minutes of participant-directed
notebook investigation. The readiness notebook is pre-work; attendees select
one of four investigation notebooks during the workshop.

The readiness notebook runs in Google Colab and verifies `cnkit`, the workshop
data, and the core calculations. It also includes an Earth Engine project check
for participants applying the method to a selected watershed. Every notebook
uses numbered operations with equations, intermediate results, interpretation,
and notes on how each relevant `cnkit` function performs its calculation.

The lecture deck supports the introduction and theory, frames the Earth Engine
exercise, launches the four investigations, and structures the final
report-outs. The Earth Engine Code Editor and investigation notebooks carry the
live analytical work.

## Workshop sequence

| Investigation | Notebook | Primary result |
|---|---|---|
| Equation behavior | `01_CN_Equation_and_Runoff_Response.ipynb` | Runoff comparison under two stated conventions |
| Spatial estimation | `02_Spatial_CN_for_a_Watershed.ipynb` | Boundary, composite CN, and spatial provenance |
| Temporal evidence | `03_Land_Cover_Change_and_Design_Runoff.ipynb` | CN trajectory, condition band, and runoff comparison |
| Observed response | `04_Event_CN_and_Antecedent_State.ipynb` | Event-derived CN and antecedent-state comparison |

## Repository structure

- `app/`, `content/`, `public/`: participant portal source
- `notebooks/`: readiness and four investigations generated by `scripts/build_notebooks.py`
- `gee/`: guided Code Editor exercise and continuing resources
- `data/`, `prepared/`: verified workshop inputs and recorded Earth Engine results
- `decks/`: editable lecture deck source
- `downloads/`: participant-ready data and slide downloads
- `docs/`: participant, instructor, design, and validation documentation
- `evidence/`: executed Earth Engine notebooks supporting the reported values
- `vendor/cnkit.py`: portable core hydrology module for the reference-data pathway

## Local development

Requirements are Node.js 22.13 or newer and Python 3.9 or newer.

```bash
npm install
npm run dev
```

The development site is served at `http://localhost:3000/`. To reproduce the
participant notebooks and static GitHub Pages site:

```bash
python scripts/build_notebooks.py
npm run pages:build
```

The static site is written to `dist-pages/`. GitHub Actions builds and deploys
that directory through the repository's Pages environment.

## Verification

```bash
python -m pip install -r requirements-dev.txt
npm test
python scripts/validate_notebooks.py
```

The notebook validator confirms notebook structure and executes the complete
reference-data pathway. The Earth Engine evidence used in the workshop was
recorded from successful runs on 6 August 2026 and is retained under
`evidence/gee-live/`.
