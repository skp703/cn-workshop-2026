# Modern Curve Number Hydrology

Participant materials for the 2026 ASCE–EWRI Watershed Management Conference
workshop on curve-number theory, spatial estimation, and Earth Observation
applications.

The four-hour workshop uses one readiness check, three integrated laboratory
notebooks, and a single lecture deck. Participants may conduct the spatial
analyses with verified reference datasets or apply the same workflow to a
selected watershed through Google Earth Engine.

## Participant entry points

- Workshop portal: <https://skp703.github.io/cn-workshop-2026/>
- Earth Engine preparation: [`docs/GEE_SETUP.md`](docs/GEE_SETUP.md)
- Participant guide: [`docs/PARTICIPANT_GUIDE.md`](docs/PARTICIPANT_GUIDE.md)
- Readiness notebook: [`notebooks/00_Readiness_Check.ipynb`](notebooks/00_Readiness_Check.ipynb)
- Lecture deck: [`downloads/2026_CN_Workshop_v3.pptx`](downloads/2026_CN_Workshop_v3.pptx)

The readiness notebook runs in Google Colab and verifies `cnkit`, the workshop
data, and the core calculations. It also includes an Earth Engine project check
for participants applying the method to a selected watershed. The laboratory
notebooks combine equations, numbered analytical steps, intermediate tables,
and notes on how each `cnkit` layer performs its calculation.

## Workshop sequence

| Module | Notebook | Primary result |
|---|---|---|
| Foundations | `01_Understand_the_Curve_Number.ipynb` | Runoff and compositing comparison |
| Spatial estimation | `02_Build_CN_for_a_Watershed.ipynb` | Composite CN, soil coverage, and provenance |
| Evaluation | `03_Change_and_Uncertainty.ipynb` | CN trajectory, condition band, and reporting statement |

## Repository structure

- `app/`, `content/`, `public/`: participant portal source
- `notebooks/`: participant notebooks generated by `scripts/build_notebooks.py`
- `data/`, `prepared/`: verified workshop inputs and recorded Earth Engine results
- `decks/`: editable lecture deck source
- `downloads/`: participant-ready data and slide downloads
- `docs/`: participant, instructor, design, and validation documentation
- `evidence/`: executed Earth Engine notebooks supporting the reported values
- `vendor/cnkit.py`: portable core hydrology module for the reference-data pathway

## Local development

Requirements are Node.js 22.13 or newer and Python 3.9 or newer.

```bash
npm install
npm run dev
```

The development site is served at `http://localhost:3000/`. To reproduce the
participant notebooks and static GitHub Pages site:

```bash
python scripts/build_notebooks.py
npm run pages:build
```

The static site is written to `dist-pages/`. GitHub Actions builds and deploys
that directory through the repository's Pages environment.

## Verification

```bash
npm test
python scripts/validate_notebooks.py
```

The notebook validator confirms notebook structure and executes the complete
reference-data pathway. The Earth Engine evidence used in the workshop was
recorded from successful runs on 6 August 2026 and is retained under
`evidence/gee-live/`.
